# TCL 55V6B (G07, Google TV 11 / SDK 30, build AR07) - debloat list used on 2026-10-24
#
# Based on examples/tcl-g07-google-tv/debloat.txt (the list tested by upstream on this same board).
# Two deliberate changes, so this file is the record of what this TV actually has:
#   - com.amazon.amazonvideo.livingroom (Prime Video) REMOVED: it is in this TV's dock.
#   - Netflix, the official YouTube app and the Chromecast receiver ADDED: the owner does not use
#     them (SmartTube and Prime Video instead), which matches the previous session's choices.
# TCL OTA (com.tcl.ttvs), the voice assistant and Chromecast stay off by choice.
#
# Apply:   tools\disable.ps1 -TvHost <tv ip> examples\tcl-55v6b\debloat.txt
# Undo:    tools\restore.ps1 -TvHost <tv ip> examples\tcl-55v6b\debloat.txt -Stock com.google.android.apps.tv.launcherx
# Nothing is uninstalled. The recovery record lives in %USERPROFILE%\.cleanyourtv\.
#
# Follows the upstream warnings: com.tcl.keyhelp, com.tcl.inputmethod.international,
# com.tcl.initsetup, com.tcl.suspension, com.tcl.micmanager, com.tcl.tv and com.tcl.tvinput stay
# enabled even though the previous session disabled some of them.
